# Шлем Пустоты — Minecraft Java 1.20.1 / Forge 47.4.10

## Что добавляет
- Шлем с зачарованным блеском и собственной текстурой.
- Рецепт: алмаз / любой цветок / алмаз; железный слиток / пусто / железный слиток.
- На клиенте, где установлен мод, игрок в шлеме полностью скрывается вместе с бронёй и предметами в руках; никнейм скрывается отдельно.
- На сервере мод снимает все эффекты зелий каждый тик, пока шлем надет.

## Сборка
1. Установи Java 17 (JDK).
2. Установи Gradle 8.x либо открой папку в IntelliJ IDEA с поддержкой Gradle.
3. В корне проекта выполни `gradle build`.
4. Готовый JAR появится в `build/libs/voidhelmet-1.0.0.jar`.
5. Для мультиплеера установи мод на сервер и на каждый клиент, которому нужно корректно видеть невидимость.

## Важно
Это исходный проект, не готовый собранный JAR. Для сборки нужен интернет, чтобы Gradle загрузил ForgeGradle и зависимости. Скрытие реализовано клиентским событием рендера, поэтому другие игроки увидят эффект только если у них тоже установлен мод. Удаление эффектов зелий происходит на сервере.
